# อัตราการเรียกและโควตา

แต่ละแพ็กเกจมีข้อจำกัด 2 แบบ คือจำนวนการเรียกต่อเดือน (โควตา) และจำนวนการเรียกต่อนาที (rate limit)

## ข้อจำกัดตามแพ็กเกจ

| แพ็กเกจ | การเรียกต่อเดือน | การเรียกต่อนาที |
| --- | --- | --- |
| Free | 1,000 | 20 |
| Starter | 10,000 | 60 |
| Pro | 50,000 | 300 |
| Enterprise | ตามตกลง | ตามตกลง |

## เมื่อเกินอัตราต่อนาที

tool จะตอบด้วยสถานะ `rate_limited` AI ส่วนใหญ่จะรอแล้วลองใหม่เอง

```json
{
  "error": {
    "code": "rate_limited",
    "message": "เรียกใช้เกิน 300 ครั้งต่อนาทีตามแพ็กเกจ ระบบจะรับคำขอใหม่ในไม่กี่วินาที",
    "retry_after_seconds": 4
  }
}
```

## เมื่อใกล้หรือเกินโควตา

- ใช้ถึง **80%** แดชบอร์ดแสดงคำเตือน และส่งแจ้งเตือนทาง LINE ถ้าเปิดไว้
- ใช้ถึง **100%** การเรียกทั้งหมดได้สถานะ `rate_limited` จนถึงรอบบิลถัดไป
- ไม่มีการเรียกเก็บเงินเพิ่มอัตโนมัติ อัปเกรดแพ็กเกจเมื่อพร้อม

## ลดการใช้โควตา

- ปิดแหล่งข้อมูลที่ไม่ใช้ AI จะเรียก tool ที่ไม่จำเป็นน้อยลง
- ให้ AI ตรวจข้อมูลเป็นชุดในครั้งเดียว แทนการถามทีละรายการ
- ดูการใช้งานแยกตามแหล่งข้อมูลได้ที่หน้าการใช้งานและแพ็กเกจ
