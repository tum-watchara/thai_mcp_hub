# Credentials (BYOK)

บางแหล่งข้อมูลให้บริการผ่านบัญชีของผู้ใช้เท่านั้น เช่น Thailand Post และ LINE Official Account เราเรียกแหล่งเหล่านี้ด้วยคีย์ของคุณเอง (Bring Your Own Key)

## เพิ่ม credential

1. ไปที่แดชบอร์ด → **Credentials** แล้วกด **เพิ่ม credential**
2. เลือกแหล่งข้อมูล ตั้งชื่อที่จำง่าย เช่น "บัญชีหลัก"
3. วางคีย์หรือ token ที่คัดลอกจากหน้า developer ของผู้ให้บริการ
4. บันทึก แล้วกลับไปเปิดใช้แหล่งข้อมูลที่หน้าแหล่งข้อมูล

| แหล่งข้อมูล | ต้องใช้ | หาได้จาก |
| --- | --- | --- |
| Thailand Post | API token | หน้าบัญชีผู้พัฒนาของ track.thailandpost.co.th |
| LINE Official Account | Channel access token (long-lived) | LINE Developers Console → Messaging API |

## เราเก็บคีย์อย่างไร

- เข้ารหัสก่อนบันทึก และแสดงในแดชบอร์ดเพียง 4 ตัวท้าย
- ใช้เรียกแหล่งข้อมูลแทนคุณเท่านั้น ไม่ส่งให้ AI
- การเรียกทุกครั้งอยู่ภายใต้เงื่อนไขบัญชีของคุณกับผู้ให้บริการ

## หมุนเวียนและลบคีย์

กด **หมุนเวียนคีย์** เพื่อแทนที่คีย์เดิม คีย์เดิมจะใช้ไม่ได้ทันที ถ้าลบ credential แหล่งข้อมูลนั้นจะถูกปิดอัตโนมัติ

<Callout type="warning">
อย่าวางคีย์ลงในแชตกับ AI โดยตรง ให้เพิ่มผ่านหน้า Credentials เท่านั้น
</Callout>
