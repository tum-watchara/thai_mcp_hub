# Plugin สำหรับ Cursor

## ขั้นตอนสำหรับ Plugin ที่เผยแพร่แล้ว

1. เปิด Cursor → Customize แล้วค้นหา Thai MCP Hub ใน Marketplace
2. กด Install เลือกติดตั้งสำหรับผู้ใช้หรือโปรเจกต์
3. เชื่อมบัญชี เลือก workspace และตรวจว่า Plugin เปิดใช้ ก่อนถามผ่าน Agent

<Callout>
Thai MCP Hub ยังไม่ได้เผยแพร่ใน Marketplace ปุ่มเชื่อมบนเว็บนี้อัปเดตเฉพาะข้อมูลตัวอย่าง ไม่ติดตั้ง Plugin ลง Cursor จริง
</Callout>

## ทดลองในเว็บนี้

เลือก Cursor ใน onboarding หรือหน้าภาพรวม ตรวจสิทธิ์ใน dialog แล้วกดยืนยันการเชื่อมต่อตัวอย่าง จากนั้นเลือกแหล่งข้อมูลและทดลอง tools ใน Playground

## สำหรับทีมพัฒนา

Cursor Plugins และ Agent Plugins สามารถรวม skills กับ MCP servers ได้ การติดตั้งผ่าน Marketplace เป็นเส้นทางหลักของผลิตภัณฑ์ ส่วนการตั้งค่า MCP เองยังเป็นทางเลือกสำหรับนักพัฒนา

ดู [คู่มือ Plugins ของ Cursor](https://cursor.com/docs/plugins) และ [MCP ของ Cursor](https://cursor.com/docs/mcp)
