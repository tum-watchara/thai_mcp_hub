# แนะนำ

Thai MCP Hub เชื่อมข้อมูลไทยกับ ChatGPT, Claude และ Cursor ผ่าน Plugin ผู้ใช้เลือกแพลตฟอร์ม เชื่อม workspace และเปิดแหล่งข้อมูลที่ต้องการ โดย MCP เป็นโปรโตคอลที่ Plugin ใช้เรียกเครื่องมืออยู่เบื้องหลัง

## ใช้ทำอะไรได้บ้าง

- งานบัญชี: ตรวจเลขผู้เสียภาษี สถานะบริษัท และคำนวณภาษี
- งาน HR: ตรวจวันหยุดและนับวันทำการ
- ร้านค้าออนไลน์: ติดตามพัสดุและจัดรูปแบบที่อยู่
- นักพัฒนา: ใช้ tools ที่มี input/output ชัดเจนกับ AI agent

## เริ่มใช้งาน

1. เข้าสู่ระบบด้วย LINE หรือ Google และเลือก workspace
2. ติดตั้ง Plugin สำหรับแพลตฟอร์มที่ใช้ แล้วตรวจสิทธิ์ก่อนเชื่อมบัญชี
3. เปิดแหล่งข้อมูลในแดชบอร์ด AI จะเห็นเฉพาะ tools ที่เปิดไว้
4. ถามผ่าน Plugin แล้วตรวจผลลัพธ์ ที่มา และเวลาในประวัติการเรียก

<Callout>
เวอร์ชันนี้เป็น frontend ตัวอย่าง การติดตั้ง การยืนยันสิทธิ์ และการตรวจพบ Plugin เป็นข้อมูลจำลอง ยังไม่มี Plugin เผยแพร่ในไดเรกทอรีหรือระบบ OAuth จริง
</Callout>

## สำหรับนักพัฒนา

MCP ยังเป็นส่วนเชื่อมเครื่องมือของ Plugin การตั้งค่า endpoint ด้วยตนเองอยู่ใน Settings → การเชื่อมต่อขั้นสูง ไม่จำเป็นสำหรับขั้นตอนติดตั้ง Plugin ทั่วไป
