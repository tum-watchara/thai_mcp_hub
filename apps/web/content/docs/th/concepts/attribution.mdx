# การแสดงที่มา

ทุกผลลัพธ์จาก tool มีข้อความแสดงที่มา (attribution) และเวลาที่ดึงข้อมูลแนบไปด้วยเสมอ เพื่อให้คุณและผู้อ่านคำตอบของ AI ตรวจสอบย้อนกลับได้

## รูปแบบ

```json
{
  "data": { "name_th": "บริษัท สยามบัญชีดิจิทัล จำกัด" },
  "_meta": {
    "source": "กรมพัฒนาธุรกิจการค้า (Open-DBD)",
    "attribution": "ที่มา: กรมพัฒนาธุรกิจการค้า (Open-DBD)",
    "fetched_at": "2026-11-13T10:42:08+07:00",
    "cached": false
  }
}
```

## ทำไมต้องแสดงที่มา

- **ตรวจสอบได้** เปิดเอกสารต้นทางดูได้เมื่อตัวเลขสำคัญ
- **รู้ความสดของข้อมูล** เห็นว่าข้อมูลถูกดึงมาเมื่อไร
- **ทำตามเงื่อนไขสัญญาอนุญาต** แหล่งข้อมูลเปิดหลายแหล่ง เช่น OpenStreetMap กำหนดให้ต้องแสดงที่มาทุกครั้ง

## แนะนำให้ AI แสดงที่มา

AI ส่วนใหญ่จะแสดงที่มาเองเมื่อเห็นข้อมูลใน `_meta` ถ้าต้องการให้แสดงทุกครั้ง เพิ่มคำสั่งนี้ใน system prompt หรือ project instructions

```text
เมื่อใช้ข้อมูลจาก Thai MCP Hub ให้ปิดท้ายคำตอบด้วยที่มาและเวลาที่ดึงข้อมูลเสมอ
```

<Callout>
ข้อความแสดงที่มาของแต่ละแหล่งดูได้ที่หน้ารายละเอียดแหล่งข้อมูลในแดชบอร์ด
</Callout>
