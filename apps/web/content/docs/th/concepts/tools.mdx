# Tools

Tool คือคำสั่งหนึ่งคำสั่งที่ AI เรียกได้ เช่น `dbd.company_lookup` หรือ `holidays.add_workdays` ชื่อ tool ประกอบด้วยรหัสแหล่งข้อมูล ตามด้วยชื่อการทำงาน

## โครงสร้างของ tool

แต่ละ tool มี

- **คำอธิบาย** ที่ AI ใช้ตัดสินใจว่าจะเรียก tool นี้เมื่อไร
- **input schema** บอกพารามิเตอร์ ชนิดข้อมูล และช่องที่จำเป็น
- **output** เป็น JSON โครงสร้างเดิมทุกครั้ง

ตัวอย่าง input ของ `holidays.add_workdays`

```json
{
  "date": "2026-12-03",
  "days": 3
}
```

ผลลัพธ์

```json
{
  "start": "2026-12-03",
  "days": 3,
  "result": "2026-12-09",
  "skipped": ["2026-12-05", "2026-12-06", "2026-12-07"]
}
```

## ทดลองก่อนใช้จริง

หน้า Playground ในแดชบอร์ดสร้างฟอร์มจาก input schema ให้อัตโนมัติ กด Run แล้วจะได้ผลลัพธ์แบบเดียวกับที่ AI ได้รับ พร้อมเวลาตอบสนองและสถานะแคช

## ข้อผิดพลาด

เมื่อเรียกไม่สำเร็จ tool จะตอบด้วยรหัสและข้อความที่อธิบายวิธีแก้ เช่น

```json
{
  "error": {
    "code": "invalid_input",
    "message": "เลขทะเบียนนิติบุคคลไม่ถูกต้อง (checksum ไม่ผ่าน)"
  }
}
```

ดู tools ทั้งหมดได้ที่[รายการ Tools](/docs/tool-reference)
