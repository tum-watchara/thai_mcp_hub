# แหล่งข้อมูล

แหล่งข้อมูล (source) คือหน่วยงานหรือบริการที่เป็นต้นทางของข้อมูล เช่น กรมพัฒนาธุรกิจการค้า หรือไปรษณีย์ไทย แต่ละแหล่งมี tools ของตัวเอง และเปิดหรือปิดแยกกันได้

## สถานะสิทธิ์การใช้งาน

ทุกแหล่งมีสถานะสิทธิ์ 1 ใน 3 แบบ

| สถานะ | ความหมาย | เปิดใช้ได้ไหม |
| --- | --- | --- |
| ใช้เชิงพาณิชย์ได้ | ข้อมูลเปิดหรือคำนวณเอง นำไปใช้ในธุรกิจได้โดยแสดงที่มา | ได้ |
| ใช้คีย์ของคุณ (BYOK) | เรียกผ่านบัญชีของคุณเอง เช่น Thailand Post, LINE OA | ได้ หลังเพิ่ม credential |
| รออนุญาต | กำลังขอสิทธิ์จากเจ้าของข้อมูล | ยังไม่ได้ แสดงเป็น "เร็ว ๆ นี้" |

เราจะไม่เปิดแหล่งข้อมูลที่ยังไม่ได้รับอนุญาตให้ใช้เชิงพาณิชย์ แม้ข้อมูลจะดูเหมือนเปิดสาธารณะ

## สถานะการทำงาน

ระบบตรวจแต่ละแหล่งทุก 1 นาที และแสดงสถานะเป็น 3 ระดับ

- **ปกติ** ตอบภายในเวลาปกติ
- **ช้ากว่าปกติ** ยังใช้ได้ แต่เวลาตอบสนองสูงกว่าปกติหรือมีข้อผิดพลาดบางส่วน
- **ใช้งานไม่ได้** แหล่งต้นทางไม่ตอบ AI จะได้ข้อความแจ้งข้อผิดพลาดที่อธิบายได้

## การเปิดและปิด

การเปิดหรือปิดแหล่งข้อมูลมีผลทันทีกับทุก client ที่เชื่อมอยู่ AI จะเห็นเฉพาะ tools ของแหล่งที่เปิดไว้ การปิดแหล่งที่ไม่ใช้ช่วยให้ AI เลือก tool ได้แม่นขึ้น
