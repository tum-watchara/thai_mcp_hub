# เริ่มต้นผ่าน Plugin

## 1. สร้าง workspace

[เข้าสู่ระบบ](/login) ด้วย LINE หรือ Google แล้วเลือกแพลตฟอร์มที่ต้องการเชื่อมใน onboarding

## 2. เชื่อม Plugin

เลือกแท็บ ChatGPT, Claude หรือ Cursor แล้วกดปุ่มเชื่อม Plugin ตรวจชื่อ workspace และสิทธิ์ก่อนยืนยัน ไม่ต้องแก้ไฟล์ config หรือคัดลอก URL ในขั้นตอนนี้

<Callout>
ปุ่มยืนยันในเว็บนี้จำลองการติดตั้งเท่านั้น ไม่มีการเปิด OAuth หรือติดตั้งบนแพลตฟอร์มจริง เมื่อเชื่อมบริการจริงแล้วจะต้องมี Plugin ที่เผยแพร่และระบบยืนยันบัญชีก่อน
</Callout>

- [ChatGPT Plugin](/docs/connect/chatgpt)
- [Claude Plugin](/docs/connect/claude-desktop)
- [Cursor Plugin](/docs/connect/cursor)

## 3. เลือกแหล่งข้อมูล

เปิดแหล่งที่ต้องการให้ AI ใช้ แหล่ง BYOK ต้องเพิ่ม credential ในแดชบอร์ดก่อน แหล่งที่รอสิทธิ์ยังเปิดใช้ไม่ได้

## 4. ลองคำถามแรก

```text
บริษัทเลขทะเบียน 0105561012346 ชื่ออะไร ยังดำเนินกิจการอยู่ไหม
```

ในบริการจริงให้เลือก Plugin ใน AI ก่อนถาม สำหรับเวอร์ชันนี้ไปที่ [Playground](/dashboard/playground) เพื่อเรียก tool ตัวอย่างและดูที่มา เวลา และประวัติใน [Logs](/dashboard/logs)

## ถ้าเชื่อมไม่ได้

- ตรวจว่าเลือก workspace ถูกต้องและเปิดแหล่งข้อมูลแล้ว
- หากข้ามการติดตั้ง ให้ย้อนกลับไปยืนยันการเชื่อมต่อตัวอย่างก่อน
- การเข้าถึง Plugin จริงขึ้นกับแพลตฟอร์ม แพ็กเกจ และนโยบายขององค์กร
- นักพัฒนาที่ต้องตั้งค่า endpoint เองดู Settings → การเชื่อมต่อขั้นสูง
