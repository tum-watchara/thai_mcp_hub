# Introduction

Thai MCP Hub connects Thai data to ChatGPT, Claude and Cursor through plugins. Choose a platform, connect a workspace and enable sources. MCP remains the protocol used by the plugin to call tools.

## Use cases

- Accounting: validate tax IDs, look up companies and calculate taxes.
- HR: check holidays and count working days.
- Online shops: track parcels and normalize addresses.
- Developers: use structured tools with AI agents.

## Getting started

1. Sign in with LINE or Google and choose a workspace.
2. Install the platform plugin and review workspace access.
3. Enable sources in the dashboard. Your AI sees enabled tools.
4. Ask through the plugin and inspect results, attribution and timestamps.

<Callout>
This is a frontend prototype. Installation, authorization and plugin detection are simulated. No plugin listing or real OAuth integration has been published.
</Callout>

## For developers

Manual MCP endpoints are under Settings → Advanced connections. Plugin installation is the primary setup flow.
