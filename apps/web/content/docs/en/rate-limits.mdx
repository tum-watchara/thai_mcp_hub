# Rate limits and quotas

Each plan has two limits: calls per month (quota) and calls per minute (rate limit).

## Limits by plan

| Plan | Calls per month | Calls per minute |
| --- | --- | --- |
| Free | 1,000 | 20 |
| Starter | 10,000 | 60 |
| Pro | 50,000 | 300 |
| Enterprise | Custom | Custom |

## Over the per-minute rate

The tool responds with `rate_limited`. Most assistants wait and retry on their own.

```json
{
  "error": {
    "code": "rate_limited",
    "message": "Exceeded the plan limit of 300 calls per minute. New requests are accepted within seconds.",
    "retry_after_seconds": 4
  }
}
```

## Near or over the monthly quota

- At **80%** the dashboard shows a warning and, if enabled, sends a LINE alert.
- At **100%** every call returns `rate_limited` until the next billing period.
- You're never charged extra automatically. Upgrade when you're ready.

## Using less quota

- Disable sources you don't use, so the AI makes fewer unnecessary calls.
- Ask the AI to process items in one batch instead of one at a time.
- See usage by source on the Usage & plan page.
