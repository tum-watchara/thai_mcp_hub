# Credentials (BYOK)

Some sources only work through the user's own account, such as Thailand Post and LINE Official Account. We call these sources with your own key (Bring Your Own Key).

## Add a credential

1. Go to the dashboard → **Credentials** and click **Add credential**.
2. Choose the source and give it a memorable name, such as "Main account".
3. Paste the key or token from the provider's developer page.
4. Save, then enable the source on the Sources page.

| Source | You need | Where to find it |
| --- | --- | --- |
| Thailand Post | API token | Developer account page on track.thailandpost.co.th |
| LINE Official Account | Long-lived channel access token | LINE Developers Console → Messaging API |

## How we store keys

- Encrypted before storage; the dashboard only shows the last 4 characters
- Used only to call the source on your behalf, never sent to the AI
- Every call is governed by your account's terms with the provider

## Rotate and delete

Click **Rotate key** to replace a key; the old key stops working immediately. Deleting a credential automatically disables its source.

<Callout type="warning">
Never paste keys into a chat with your AI. Add them on the Credentials page only.
</Callout>
