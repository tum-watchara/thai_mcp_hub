# Cursor plugin

## Once the plugin is published

1. Open Cursor → Customize and find Thai MCP Hub in the Marketplace.
2. Select Install and choose user or project scope.
3. Connect your account, select your workspace and enable the plugin before using Agent.

<Callout>
Thai MCP Hub has no published Marketplace listing yet. Confirming a connection here updates sample data and does not install anything in Cursor.
</Callout>

## Try the prototype

Choose Cursor in onboarding or Overview, review access and confirm the demo connection. Then enable sources and try tools in the Playground.

## Developer integration

Cursor Plugins and Agent Plugins can package skills and MCP servers. Marketplace installation is the primary user flow; manual MCP configuration remains a developer option.

See [Cursor Plugins](https://cursor.com/docs/plugins) and [Cursor MCP](https://cursor.com/docs/mcp).
