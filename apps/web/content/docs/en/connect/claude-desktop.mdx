# Claude plugin

## Once the plugin is published

1. Open Claude or Claude Desktop → Customize → Plugins and browse the directory.
2. Choose Thai MCP Hub, select Add and follow the account connection flow.
3. Choose a workspace, review access and enable sources before asking.

<Callout>
Thai MCP Hub is not yet published in the Claude directory. This website simulates connection only. Platform availability depends on the account and organization policy.
</Callout>

## Try the prototype

Choose Claude, confirm the demo connection and continue onboarding. No desktop JSON configuration or helper installation is required for this sample flow.

## Developer integration

Claude plugins can package MCP connectors and skills. MCP remains the underlying data connection. Production requires packaging, account authorization and publication.

See [Claude plugin development](https://claude.com/resources/articles/build-plugins-for-claude) and the [unified directory guide](https://support.claude.com/en/articles/14328846-browse-skills-connectors-and-plugins-in-one-directory).
