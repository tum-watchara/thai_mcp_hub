# ChatGPT plugin

## Once the plugin is published

1. Find Thai MCP Hub in the ChatGPT Plugins directory.
2. Install it, connect your account and review workspace access.
3. Type @ in a chat and choose the installed plugin to use its tools.

<Callout>
Thai MCP Hub has no published directory listing yet. The onboarding and dashboard buttons simulate a connection; they do not create or publish a plugin.
</Callout>

## Try the prototype

Choose ChatGPT, confirm the demo connection and enable sources. The simulated detection state uses the selected platform.

## Developer integration

Plugins package MCP servers and may include skills or UI. Real deployment still needs account authorization, testing and publication. MCP remains the underlying protocol.

See the [OpenAI plugin quickstart](https://developers.openai.com/plugins/quickstart) and [custom MCP plugin guide](https://developers.openai.com/api/docs/guides/custom-mcp-server). The former Settings → Connectors setup is no longer the primary product journey.
